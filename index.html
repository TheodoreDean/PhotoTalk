给 App Store Connect 的填写对照

审核员与开发者可据此核对「App 隐私」营养标签。与当前 PhotoTalk 代码行为一致： Data Not Collected（不收集数据）。

App Store 隐私问题 PhotoTalk 答案
是否收集数据并关联到用户身份？ 否。无账号、无用户 ID、无设备指纹上报。
是否用于跟踪（Tracking）？ 否。未接入 ATT / 广告标识符 / 跨 App 追踪。
照片与视频 不作为「收集」申报。仅在设备本地选择、处理并可选保存 PNG；开发者不接收副本。
其他用户内容（隐藏文字、密码） 不收集。明文经 AES-GCM 加密后写入像素；密码仅用于本地派生密钥，从不上传。
诊断 / 分析 / 崩溃 不收集。当前版本未集成第三方分析或崩溃上报。
联系信息 / 位置 / 财务 / 健康 不涉及、不收集。
Privacy Policy URL（上架必填） 部署到 GitHub Pages 后，在 App Store Connect → App 隐私 / App 信息中填写本站的隐私政策地址，例如： https://<your-username>.github.io/PhotoTalk/privacy.html （英文页可用 privacy-en.html）。

本地处理

隐写与加解密均在设备完成，不经过开发者服务器。

相册权限

读取：选择载体图；写入：保存无损 PNG。用途仅限上述功能。

密码

由您创建；用于 PBKDF2 派生密钥。忘记密码将无法解密隐藏内容。

剪贴板

仅在您主动点击「复制」时，把已解密文本写入系统剪贴板。
